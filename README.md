## 🚀 Como executar localmente

Não há dependências ou processo de instalação. Para visualizar o projeto:

1. Clone o repositório:

   ```bash
   git clone https://github.com/lucasjesus00/lucas-mendes-portfolio.git
   ```

2. Entre na pasta:

   ```bash
   cd lucas-mendes-portfolio
   ```

3. Abra o arquivo `index.html` diretamente no navegador ou utilize a extensão Live Server no VS Code.

## 🖼️ Recursos

- layout totalmente responsivo;
- tema escuro inspirado em interfaces de desenvolvimento;
- menu móvel com estados acessíveis;
- animações ativadas ao rolar a página;

- atualização automática do ano no rodapé;
